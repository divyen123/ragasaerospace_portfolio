# RAGAS Aerospace — Decisions in the Sky

Pioneering autonomous aerial intelligence with indigenous deep-tech solutions. RAGAS Aerospace builds state-of-the-art intelligent systems for defense, security, industrial monitoring, and precision agriculture.

This repository houses the source code for the **RAGAS Aerospace Interactive Portfolio & Commercial Investor Dashboard**, deployed at [raic.ragasgroups.com](https://raic.ragasgroups.com/).

---

## 🚀 Key Features

* **Real-Time Adaptive Intelligence Core (RAIC)**: Interactive technology insights demonstrating decentralized autonomous decision-making and edge computing.
* **Advanced Swarm Architecture**: Real-time visualization of swarming protocols, obstacle avoidance, and dynamic routing topologies.
* **Tactical Hardware Integrations**: Technical specifications highlighting edge processing units like **NVIDIA Jetson** and **Crossflight V1.1** avionics.
* **Commercial Viability Dashboard**: Custom, responsive SVG analytical charts (Pie, Doughnut, Column, and Area charts) illustrating market segments, projected revenue streams, employment growth trendlines, and conventional efficiency gains.
* **Interactive Pitch Report**: Organized categorization of industry-focused problem statements, regional strategic alignments (Make in India, Atmanirbhar Bharat), and long-term research roadmap.
* **Cinematic Experience**: Hands-free intro animation revealing the brand wings logo with ease-in/out scale and breathing ambient glows, fully responsive and optimized for mobile/desktop.

---

## 🛠️ Technology Stack

* **Core Framework**: React 18 & Vite
* **Design & Styling**: Tailwind CSS, CSS Custom Keyframes & Variables
* **Animation Libraries**: Framer Motion & GSAP (GreenSock Animation Platform)
* **3D Visualizations & Assets**: Three.js, React Three Fiber (R3F), and `@react-three/drei`
* **Icons & UI components**: Lucide React & Swiper
* **Browser Compatibility**: Polyfilled for older desktop/browser agents (`es2015` compilation target) with Safari-safe pure CSS SVG transition implementations.


---

## 🚀 Deployment & Infrastructure

The platform is deployed using modern cloud hosting infrastructure configured for automatic delivery and domain resolution:

* **CI/CD Deployment Pipeline**: The project utilizes a GitHub-integrated CI/CD workflow. Any code updates or feature enhancements pushed to the `main` branch trigger an automated build and deployment process, ensuring the live application is continuously up to date without manual intervention.
* **Domain Management**: Domain routing is configured for the **[raic.ragasgroups.com](https://raic.ragasgroups.com/)** subdomain. It links directly to the deployed instance with secure SSL/TLS termination automatically handled and renewed at the edge.
